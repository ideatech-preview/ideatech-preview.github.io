デザインシステム

IDEATECHサイトのデザインを支えるルール体系。バージョン履歴をすべて残し、制作の変遷を記録します。

  3. デザインシステム
v6 CURRENT 2026-11-09〜

文字色を白 #ffffff と黒 #1d1d1f の2色だけにした（明るい地は黒・暗い地と色の塗りは白）。透過で文字を薄めず、アクセント色やグラデーションの文字も使わない。色はアイコン・線・枠・塗りにだけ使い、文字の強弱は大きさと太さでつける。本文の太さを 500 から 400 に戻し、マーカーを引く文字は太字にした。ボタン（角丸8px・1ページ2色・グラデーション禁止）・テキストリンク（細い下線＋ホバーで薄く）・字間0（palt も使わない）を加えた。文字色は CI（check:text-color）で検査する。
v5 ARCHIVED 2026-10-29〜2026-11-08

正典をWebページからリポジトリ直下の DESIGN.md へ移し、人もAIも同じ1枚を読む形にした（このページは DESIGN.md をそのまま表示）。日本語の本文書体を全ページで Noto Sans JP に統一し、文字の太さを語彙に追加（本文500・強調700・見出し800）。antialiased をやめ、コントラスト検査を半透明の色にも効かせた。「人間には要点、AIには全文」の折りたたみの型を追加。
v4 ARCHIVED 2026-09-09〜2026-10-28

v3 の4階層ルール体系（どこに効くか）に、「ルールの強さ」の3段階（どれだけ強いか）を追加。語彙は閉じ、用法は開く。① 可読性の下限（本文16px・全用途12px・コントラスト4.5:1・フォーム16px）は CI で検査して落とす。② 語彙はサイズ8段階・行間4段階・角丸4段階に集約。モバイルはスケールを分けず、見出し帯だけを clamp() で可変にする。
v3 ARCHIVED 2026-05-20〜2026-09-08

v2 の4階層ルール体系を継承しつつ、CMS プラネットルール（コラム / ニュース / セミナー / 導入事例）を詳細化。Notion 編集ルール・見出しマッピング（heading_N → h(N)）・本文スタイル仕様（h1〜h4・リスト・引用・テーブル）を明文化し、記事運用チーム向けライブプレビュー（/sample/cms-headings/）を併設。
v2 ARCHIVED 2026-05-07〜2026-05-19

MOON / コーポレート / プラネット / サテライトの4階層ルール体系。v13.0 TPI パレット + Inter / Noto Sans JP / Roboto / JetBrains Mono。6プラネット×3グループ。CMSプラネットの詳細記述は v3 で更新。参照非推奨。
v1 ARCHIVED 〜2026-05-06

バイブコーディング初期段階のデザインシステム。3章構成（カラー / フォント / レイアウト）。記録目的で凍結保存。参照非推奨。
