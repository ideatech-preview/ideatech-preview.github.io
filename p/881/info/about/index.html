ロゴに込められた意味

光の三原色 RGB

IDEATECHのロゴは、光の三原色である RGB（Red・Green・Blue）で構成されています。

それぞれの色には、私たちが大切にしている3つの要素が込められており、それらが重なり合うことで、新しい未来が生み出されていくというコンセプトを体現しています。

  • Red — アイデア｜着想・発想・創造性
  • Green — 人｜チーム・関係性・成長
  • Blue — テクノロジー｜AI・データ・仕組み化

5つのバリュー

IDEATECHのメンバーが日々の行動指針として大切にしている5つの価値観。

VALUE 01

be RITA

利他の心こそ繁栄の道

自分より先に相手の幸せを考え行動することが、長期的な信頼と成長を生む。

VALUE 02

be WATER

水のように柔軟に

どんな状況にも形を変えて適応し、しなやかに変化し続ける力がイノベーションを生む。

VALUE 03

be POTATO

泥臭く、生命力をもって

華やかさより実直さ。土の中でも力強く育つジャガイモのような粘り強さを大切に。

VALUE 04

be WASABI

ワサビのように良き引き立て役に

主役を輝かせる脇役としての誇り。クライアントの魅力を最大に引き出す。

VALUE 05

be FIRE

情熱を灯し、未来を照らす

熱意なき行動に価値はない。自ら燃え、周囲を照らす炎のような情熱を持ち続ける。
