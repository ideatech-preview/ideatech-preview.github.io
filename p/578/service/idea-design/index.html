// THE PROBLEM

そのサイトは、AIから見えていますか？

人の目にはちゃんと見えていても、AIにとっては中身が読み取れないサイト構造の可能性があります。
AI対策は、構造化データもクローラー設定も、画面上には現れにくいもの。
サイトの更新頻度や新しさとは別で考えるべき、根本的に対処すべき領域です。

BEFORE

未対策のサイト

AIからは空っぽのサイトのように見えてしまう

  • 本文がJSで描画される前の、骨組みしか返らない。
  • クローラーを弾いていて、そもそも読みに来られない。
  • リンク切れやサイトマップ未掲載で、存在しないページとして扱われる。

AFTER

IDEA DESIGN®

AIが読み取りやすい構造

  • 本文がJSなしで届き、そのままAIに読まれる。
  • クローラーを通し、robots.txt と llms.txt で入口を示す。
  • サイトマップと導線が一致し、すべてのページに辿り着ける。

IDEA DESIGN®は、“変化し続けることを普遍とするデザイン”をモットーとし、
常に新しく生まれ変わるWEBをオーケストレーションします。

「IDEADESIGN®」は株式会社IDEATECHの登録商標です。

CHECK_01

本文が、JSなしで届いているか

サーバが骨組みだけを返し、中身をJavaScriptで描画しているサイトは少なくありません。
主要な生成AIのクローラーはJSを実行しないため、人には見えている本文が、AIには空ページとして届きます。

CHECK_02

AIのクローラーを、通せているか

GPTBot・ClaudeBot・PerplexityBot などが読みに来られる状態か。
ボット対策を既定のままにすると、AIのクローラーまで遮断してしまうことがあります。読める状態は、引用される前提です。

CHECK_03

ページが、たどり着ける状態か

ナビにリンクがあるのにサーバが4xxを返す、旧URLのまま貼られている、サイトマップに載っていない。
いずれも人には見えていても、AIにとっては存在しないページとして扱われます。

CHECK_04

構造化データが、入っているか

Organization・FAQPage・Article など、そのサイトに実在する情報に該当する型が実装されているか。
これが無いと、本文が届いてもAIは事実として取り出せず、引用元として扱えません。

// THREE PILLARS

AIに推奨される状態を
「つくり、可視化し、育てる」3つの柱

① 実装する

AIに読まれ、引用されるためのサイト構造を、標準モジュールとして実装します。

IDEA DESIGN®は、この両輪をひとつの運用に束ねている点が最大の特徴です。

// TWO WHEELS

AI対策は、「器」と「中身」の両輪。

AI対策というと、構造化データやrobots.txtの整備といった技術的な話に寄りがちです。
しかし、AIに読まれるサイトの構造（器）と、AIに引用される情報そのもの（中身）は、
どちらか一方では機能しません。

観点 器AI対策サイト 中身マーケティング・アセット
役割AIに読み取られ、引用・推奨されうる状態をつくるAIが引用したくなる価値ある情報（一次情報など）を積み上げる
具体構造化データ、llms.txt／robots.txt、外部参照データベース、表示速度、配信基盤など調査データ、業界レポート、白書、専門家コラム、E-E-A-Tコンテンツなど
欠けると良い情報を出しても、AIに読まれない（透明なサイト）読まれても、語る材料がない（中身のないサイト）
担当IDEA DESIGN®（Octy Core）リサピー®／レポピー®／ハクピー®／コラピー®

器だけ整えても引用されず、中身だけつくっても読まれない。
この両輪をひとつの運用として回すのが、IDEA DESIGN® の設計です。

IDEA DESIGN®はまず、Webサイトを適切な「器」として再構築することをファーストステップとし、その土台ができた後のセカンドステップとして、より本質的な「中身」の充実を計ります。海外のマーケティングでは、コンテンツのことを「マーケティング・アセット（資産）」と呼びます。単発の作業物ではなく、出すほど積み上がる資産だという捉え方です。

// THE CONCEPT

【動的平衡（どうてきへいこう）】とは、
変わり続けることで、崩れない状態を保つこと。

生命が細胞を絶えず入れ替えながら、常にフレッシュな自分の輪郭を保ち続けるように。
動的平衡WEBサイトは、流動的に情報が更新され続け、逆説的に芯（コアなアイデンティティ）だけが残る、新しいWEBの考え方です。

PARADIGM

デザインを「固める」時代は終わった。

ブランドガイドラインを完璧に固めて納品し、3年は触らない ── そんなデザインは、社会と市場の流動性が一定の閾値を超えた今、固めた瞬間に腐りはじめる。
これからのデザインは流動的に「変わり続ける」ことが基本となる。

PRINCIPLE

「変わらない芯」が浮き彫りになる。

変わり続けるからこそ、自分たちの「ずっと変わらない芯」が浮き彫りになる。
企業の存在意義、顧客との関わり方、人としての在り方….。
己に対する解像度を上げることで、強みを知り、弱点を克服することにつながる。

// MANIFESTO

デザインの常識を覆す、新時代への挑戦

CHALLENGE

デザインガイドラインをあえて「定め切らない」

ガイドラインを定めることは、ブランドイメージを守る一方で、変化への柔軟性や汎用性を下げることとトレードオフです。
また、AIとの共創の可能性に「フタをする足枷」にもなります。
IDEA DESIGN®では、定めるガイドラインを「最低限度」に抑え、もっとも効果的な最新のデザインを探究し続けるスタイルに振り切ります。
ただし、AIに任せきりにはしません。最終的なアウトプットのクオリティは、プロのデザイナーの目で必ず担保します。

// THREE LAYERS

「動的平衡WEBサイト」は、3つのレイヤーで構成される。

01

第1層｜STRUCTURE（器）

「構造化」レイヤー

AIに正しく読み取ってもらうためのサイトの構造設計です。
AIから引用される「器」をつくる層で、前述のモジュールが担います。IDEA DESIGN®のサービス領域は、この層にあたります。

  • LLMO / AEO を前提にしたサイト設計と構築
  • Schema.org / 構造化テキスト / 定義文最適化
  • 必要に応じて、大胆なリニューアルも積極的に

→ AIから引用される「器」をつくる

02

第2層｜CONTENT（中身・資産）

「コンテンツ」レイヤー

商品やサービスの情報を常に新しく保ち、新規コンテンツを継続的に追加する層です。
器に注がれ続ける中身であると同時に、マーケティング・アセットとして蓄積される資産にもなります。AIから「動いている会社」と認識され続けるのは、この層が動いているからです。

  • サービス情報の最新化／新規コンテンツの継続追加
  • 1週間単位の定例MTGで見直し、即サイト反映
  • 社内会議音源 → AI処理 → サイト自動更新

→ マーケティング・アセットとして積み上がる

03

第3層｜CORE（核）

「思想・体制」レイヤー

サイトを動的平衡に保ち続けるには、会社の文化や意思決定の体制そのものを、変化に強いかたちへ変える必要があります。
IDEA DESIGN®は、その風土づくりにも貢献します。

  • 経営／広報チームへの思想インストール
  • 「定め切らない」運用カルチャーの構築
  • 高速PDCAを回し続けるための意思決定体制

→ 会社の文化やこだわりという「核」が浮き彫りに

第1層・第2層が変化し続けるからこそ、本質的に変わらない第3層の「核」が浮き彫りとなる。
これからのブランディングとは、カラーやトンマナといったようなCIを定めることではなく、 会社として「何を大事にし、どう在るべきか」といったような、本質的な思想を探究する終わりなき旅なのだと IDEA DESIGN® は考えています。
変化し続けることと、変わらないことは矛盾しません。

// FAQ

よくあるご質問

「動的平衡WEBサイト」と一般的なWeb制作会社の違いは何ですか？+
一般的なWeb制作会社は「制作」と「保守（軽微な修正）」が中心で、数年に一度のリニューアルを想定した固定的な関わり方です。動的平衡WEBサイトは、AEO対策を徹底した制作に加え、毎週単位のアップデート運用と、変化を前提とした思想・体制構築までをひとつの商品として束ねます。また、IDEA DESIGN®では、御社専用のAIエージェント（Octy）を当社側で育て、御社はチャットで依頼するだけで運用できることも特徴です。
AIエージェントは具体的に何をしてくれるのですか？+
主に5つの領域を担当します。①サイトのデザイン・コーディング ②構造化データ整備（LLMO/AEO対策） ③24時間サイトを巡回して異常検知、軽微なものであれば自動修正、重大なものであれば人間にアラート ④外部APIとの連携 ⑤サイトのアップデート
どんな企業に向いていますか？+
AI時代に「選ばれ続ける状態」をWEBサイトからダイナミックに設計・構築したい中小企業の経営者・広報・マーケティング責任者に向いています。逆に、大手・エンタープライズなど、既存のブランドイメージが強固な企業には向いていません。
既存のWebサイトを残したまま、AIエージェントだけ導入することはできますか？+
使用されているツールやプラットフォームによっては導入が難しいケースもあります（ノーコードWeb制作プラットフォームなど）。基本的には、ゼロからAIエージェントを主軸としたサイト構築が理想的であるため、まずはサテライトサイト（LPなど）から段階的に導入いただくことをおすすめします。
毎週本当に変えるべきことがあるのですか？+
事業を真剣にやっている限り、必ずあります。新しい問い合わせ、よくある質問の更新、業界の動き、競合の発信、社内の事例、AIで参照されたキーワードの変化 ── これらすべてが「変えるべき項目」の素材になります。
AEO対策とは具体的に何をしますか？+
Schema.org JSON-LDの設計、構造化テキスト、定義文の最適化、AIに引用されやすい情報密度の設計、独自データ・一次情報の組み込みなど、AIが正確かつ優先的に参照できる形にサイトを設計します。
更新作業は誰がやりますか？社内で運用できますか？+
基本はIDEATECH側で更新作業を担当します。週次MTGで貴社から「変えたい項目」をいただき、こちらでAIと協業して最短即日でリリースします。
AIエージェントに任せきりになって、人の手が入らなくなりませんか？+
任せきりではありません。AIエージェントが担うのは「日々の更新・改善・パトロール」などのタスクがメインで、コンテンツの方向性や重要な変更は必ず人間（IDEATECH側）がレビュー・承認するフローを取ります。
AIエージェントが間違った情報を発信してしまうことはありませんか？+
リリース前に、必ず人の目で検閲を行いますのでご安心ください。AIが勝手に知らない情報を生成して、サイトにアップロードすることはありません。
契約期間や解約条件を教えてください+
運用ループの効果が現れるまでに最低3ヶ月程度必要なため、初回契約は6ヶ月〜を推奨しています。詳細は事業の状況をお伺いしたうえで個別に設計します。
料金はどのくらいですか？+
サテライト（LP）／プラネット（CMS）／コーポレート（CMS＋AIチャット）の3プランをご用意しています。いずれも「初期費用＋月額運用費」の構成で、最低契約期間はプランにより異なります。具体的な機能と料金は、サービス資料でご確認いただくか、無料相談でご案内します。
サイトのコード（リポジトリ）は自社で所有できますか？+
標準は当社が運用ごとお預かりする形です。リポジトリの御社所有・ライセンス利用は、将来的な提供形態として個別にご相談ください。
解約したら、サイトやデータはどうなりますか？+
案件コード一式をお渡しします（Octy Core等の共通基盤を除く）。コンテンツ（Notion）と顧客データ（HubSpot）は常に御社所有・御社契約のため、データで縛ることはありません。
頻繁にサイトを変えて、SEO評価が不安定になりませんか？+
URL構造・主要な検索意図に応えるコンテンツの骨格は固定し、鮮度に関わる部分を継続更新する設計です。変更はすべて計測とセットで行い、悪化があれば即時ロールバックします。
Claude（AIモデル）に障害や仕様変更があった場合は？+
サイト自体は静的に稼働しており、AIの障害でサイトが止まることはありません。運用作業は当社側で代替手段を確保しています。
